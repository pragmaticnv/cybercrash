All ATM locations and financial/cybercrime events are synthetic. Bank names are realistic display/operator labels only. Geographic layer has 288 synthetic subzones, exactly 8 per each of 36 States/UTs. Existing synthetic ATM coordinates are preserved; zone assignments and location-dependent relationships are rebuilt. ML dataset remains 1,440,000 rows using 144 candidate zones per case; actual target zone is always included for cash-out cases.
